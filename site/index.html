One viewer for every file

AnyView previews Word, Excel and PowerPoint files, PDFs, images, video, audio, code and more, entirely in the browser. No dependencies, no server, nothing uploaded.

npm install @buffmomo/anyview
  • Zero runtime dependencies. Every parser is part of the package.
  • Private. Files are read on the visitor's device.
  • Small. Each format's code loads only when it is needed.
  • Works anywhere. Plain JavaScript, a web component, React and Vue.

Quick start

import { createViewer } from '@buffmomo/anyview';

const viewer = createViewer('#preview', {
  src: '/files/quarterly-report.xlsx',
  theme: 'auto',
});

viewer.on('load', ({ format, file }) => {
  console.log(`Showing ${file.name} as ${format.label}`);
});
<script type="module">
  import '@buffmomo/anyview/element';
</script>

<any-view src="/files/contract.docx" theme="light" style="height: 600px"></any-view>
import { AnyView } from '@buffmomo/anyview/react';

export function Preview({ file }) {
  return <AnyView src={file} style={{ height: 600 }} onError={console.error} />;
}
<script setup>
import { AnyView } from '@buffmomo/anyview/vue';
defineProps(['file']);
</script>

<template>
  <AnyView :src="file" style="height: 600px" />
</template>

The container needs a height. Sources can be a URL, a File, a Blob or raw bytes.
